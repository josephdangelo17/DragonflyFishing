This game was made in windows using Visual Studio. The solution file is DragonflyFishing.slnx. All code is contained in the subfolder DragonflyFishing. The work is also in the GitHub repo https://github.com/josephdangelo17/DragonflyFishing.git.

There are two main() functions in this project, being in game.cpp and test_suite.cpp. Game.cpp contains the actual game, while test_suite.cpp contains the ai generated tests for the code. Only include one of these at a time, or alternatively comment out one of the mains.
